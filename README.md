# Zane Invest WORKBENCH · 机构级智能投研工作台

个人 A股/港股/美股 投研决策辅助系统：五步投研法 + 财务排雷量化取证 + 真实行情/财报数据 + DeepSeek AI 研判 + 决策纪律闭环。

> **定位**：投研方法论 + 真实数据 + 决策纪律的**个人工具**。不是"预测神器"，不构成投资建议。

## 🚀 快速开始

### 环境要求
- Node.js ≥ 18（开发用 24 实测）
- Python 3.9+（可选，仅机构持仓数据服务需要；**不装也可用**，公募/社保自动回退静态快照）

### 1. 安装依赖
```bash
npm install
```

### 2. 配置环境变量
```bash
cp .env.example .env
# 编辑 .env：填 DEEPSEEK_API_KEY（必须，否则 AI 降级为本地规则）；公网部署建议设置 ACCESS_TOKEN/VITE_ACCESS_TOKEN
```

### 3. 启动（两个进程）
```bash
# 终端 1：机构持仓数据服务（公募/社保重仓真实数据；可选）
npm run akshare            # http://127.0.0.1:8765

# 终端 2：主应用
npm run dev                # 默认 http://localhost:3999
```

> 端口冲突时改 `.env` 里的 `PORT`。本地 3000/3100 常被占用，默认已改为 3999。

### 4. 生产部署
```bash
npm run build              # 产出 dist/（前端静态 + server.cjs）
NODE_ENV=production PORT=3999 npm start
```
公网部署**务必**：
- 设置 `ACCESS_TOKEN` + `VITE_ACCESS_TOKEN`（所有 /api 需 Bearer 令牌）
- 用 Nginx/HTTPS 反向代理，或至少置于内网
